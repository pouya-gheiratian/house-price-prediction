# House Price Prediction

A Machine Learning project developed using Python for predicting house prices based on property features.

## Features

* Data preprocessing
* Exploratory Data Analysis (EDA)
* Feature engineering
* Model training and evaluation
* House price prediction

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-Learn
* Matplotlib

## Project Goal

The objective of this project is to build a predictive model capable of estimating house prices based on different property characteristics.
